# I Need Good Script

A clean, modern script hub for **+1 Muscle to Break Walls** (Roblox).

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/xlordan/I-Need-Good-Script/main/INeedGoodScript.lua"))()
```

## Features

- **Farm** - Auto Click (adjustable CPS), Auto Rebirth (100 / 10 / 1 / Best), instant x100 rebirth
- **Event** - Auto Collect Pumpkins, Auto Claim Event Quests, world teleports
- **Player** - WalkSpeed, JumpPower, Infinite Jump, Anti-AFK, Reset Character
- **Stats** - live strength, wins, rebirths, rates and multipliers
- **Settings** - Low Graphics, keybinds, saved config

## Keybinds

- `RightShift` - show / hide the menu
- `M` - Auto Click
- `N` - Auto Rebirth
